# Dependencies

The current sandbox includes a large collection of common Debian/Ubuntu
packages.  Below is a concise excerpt of the most frequently used
packages in this repository.  Full listings can be obtained with
`dpkg -l`.

| Name | Version | Description |
|------|---------|------------|
| `adduser` | `3.137ubuntu1` | add and remove users and groups |
| `apparmor` | `4.0.1really4.0.1-0ubuntu0.24.04.4` | user‑space parser utility for AppArmor |
| `bash` | `5.2.12(1)-release` | GNU Bash shell |
| `coreutils` | `8.32` | basic file, shell and text utilities |
| `dpkg` | `1.22.5ubuntu3.12` | package manager |
| `grep` | `3.11` | search text with regular expressions |
| `sed` | `4.9` | stream editor |
| `wget` | `1.21.3` | network download utility |

These are the only packages explicitly referenced by the repository
documentation or scripts.  If additional packages are required, extend
the list and update the repository documentation accordingly.
